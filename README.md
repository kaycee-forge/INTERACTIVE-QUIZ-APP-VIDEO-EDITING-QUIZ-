
# Interactive Quiz App - Video Editing Quiz

This is an interactive quiz app built to test your knowledge on video editing concepts. It is among the project for the 200 days of coding
Challege

## Features

- Multiple choice questions on video editing.
- Keeps track of the user's score.
- Interactive UI with next buttons to navigate through questions.

## Technologies Used

- **HTML**: Structure of the quiz app.
- **CSS**: Styling and layout.
- **JavaScript**: Logic for the quiz functionality.

## How to Run

1. Clone the repository.
2. Open the `index.html` file in your browser.
